Repository Architecture

Source Code Directory

Inspect any module directly on GitHub. Every file is modular, documented, and ready for global open-source exploration.

agent.yaml Agent Spec

Declarative Docker Agent v4 specification. Configures Ollama model mapping, tools (filesystem, shell, think, todo), and SRE investigation prompts.

View agent.yaml on GitHub →
analyze_logs.py Python Diagnostic

Standalone regex log scanner for 5xx errors, TLS expiration patterns, database timeouts, and JVM heap pressure reporting.

View analyze_logs.py on GitHub →
run.bat Windows CMD

Windows Command Prompt launcher. Features automated Ollama background bootstrapping, model pre-warming, and CRLF line normalization.

View run.bat on GitHub →
run.ps1 PowerShell

Native PowerShell & Windows Terminal launcher. Auto-detects Qwen 2.5 7B, handles winget installation, and pins the model in memory.

View run.ps1 on GitHub →
run.sh Bash / POSIX

POSIX-compliant shell script for Linux and macOS. Auto-starts Ollama daemon and sets OLLAMA_KEEP_ALIVE=-1 for zero cold-start delay.

View run.sh on GitHub →

Open on GitHub ↗ 
# Ensure Ollama keeps models loaded indefinitely in memory (Always Awake)
$env:OLLAMA_KEEP_ALIVE = "-1"

# Check & pre-warm Qwen 2.5 7B
$null = Invoke-RestMethod -Uri "http://127.0.0.1:11434/api/generate" -Method Post -Body '{"model": "qwen2.5:7b", "keep_alive": -1}' -ContentType "application/json" -TimeoutSec 5 -ErrorAction SilentlyContinue

# Launch Dark Matter TUI
$agentYaml = Join-Path $PSScriptRoot "agent.yaml"
& docker agent run --app-name "Dark Matter" $agentYaml @args

docker agent run --app-name "Dark Matter" "$DIR/agent.yaml" "$@"

Getting Started

One-Click Setup & Execution

Clone the repository and run the native launcher. The system handles Ollama checks and model downloads automatically.

# 1. Clone the repository

bash / git 
git clone https://github.com/unknown404-practice/autonomous-code-writer.git
cd autonomous-code-writer

# 2. Run Dark Matter (Auto-pulls Qwen 2.5 7B if missing)

cross-platform shell 
# Windows PowerShell / Windows Terminal:
.\run.ps1

# Windows Command Prompt:
run.bat

# Linux / macOS:
chmod +x run.sh && ./run.sh
